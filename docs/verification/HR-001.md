# HR-001 出勤打卡驗證紀錄

日期：2026-10-28。Issue #32。分支：`feat/hr-001-attendance`，由 ECOM-003 最新 Draft PR head `feat/ecommerce-003-inventory` 建立；PR 以此前置分支為 base。

## 交付

- Owner 可從既有租戶 membership 選取員工、設定選填員工編號與啟用狀態；跨租戶 membership 不可加入。
- Owner／Member 的已驗證 membership 可替已啟用員工資料的本人打卡，Owner 可查本租戶員工與歷史；Member 不能查其他人的出勤。
- clock-in 用 PostgreSQL server default time，clock-out 由 server 寫入 UTC；API 拒絕 client clock 時間、員工 ID 或未定義欄位。Tenant timezone 可由 Owner 設定，初始 fallback 為 `Asia/Taipei`；歷史紀錄依 tenant timezone 計算 business date。
- 同 tenant/employee 對應一筆 open attendance；tenant row lock、租戶範圍冪等 key 及 PostgreSQL partial unique index 防重與併發雙打卡。
- HR profile 停用前必須先結束未下班紀錄。Owner 可用附原因、更正前後值的 append-only adjustment 修正打卡，亦可為已失效 membership 補登漏打的下班時間。資料表 trigger 禁止刪除出勤與更正紀錄。
- 新增 `docs/HR-REQUIREMENTS.md`，將登入會員限定、Asia/Taipei、Owner correction、排班／休假／加班／薪資／GPS 排除項列為待最終確認的初版預設。
