# WMS-004 驗證紀錄

Issue #19 · [Draft PR #20](https://github.com/Jlumin/multi-tenant-saas/pull/20) · 暫定即時調撥假設待審查

## 驗收範圍

- 同倉移位與跨倉即時調撥使用同一張 WMS 單據；來源扣帳、目的入帳、單據狀態、異動帳及 metadata audit 同交易提交或回滾。
- Owner-only 過帳，Member 可建立草稿；租戶邊界由有效 membership 決定。
- 禁止負庫存；冪等重送不重複異動；單據與異動保留不可變。
- 在途、部分收貨、差異與中途取消不在本 Issue 範圍。即時模式尚待使用者確認。
