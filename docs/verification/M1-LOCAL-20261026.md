# M1 本機人工驗證補充

日期：2026-10-26（Asia/Taipei）。補充 AUTH-001 / TENANCY-001 原始驗證報告；僅本機開發環境，不代表正式部署或全部 M1 驗收。

## Google 與第一個租戶

- 操作者完成真實 Google 登入；瀏覽器帳號頁顯示「已登入」。回呼後可持續讀取 session。
- 首次回呼曾出現 invalid_code。安全診斷確認 Google 回覆 invalid_client；本機 Client ID 與下載 JSON 中的 Client ID 不一致，Secret 則一致。改用 JSON 中同一組憑證並重啟後，操作者重新登入成功。
- OAuth 憑證只保存在 Git 忽略的本機 .env，不記錄憑證、個人 email、session/token 或 OAuth JSON。
- 開發 PostgreSQL 已套用三份既有 migration，migrate status 顯示 up to date；沒有 reset、刪除 volume 或變更 migration。
- 經操作者確認，用既有 tenant:provision CLI 建立「開發測試公司」（slug dev-test-company），將目前已驗證帳號設為 Owner。
- 瀏覽器 /workspaces 顯示一個工作空間；選取後可見 Owner 邀請表單、一位有效 Owner 與 tenant.provisioned 審計紀錄。
