# ADR 0008：WMS 盤點、期初庫存與沖銷

- 狀態：Draft，對應 WMS-005 / Issue #21
- 日期：2026-10-27

## 背景

WMS 已有商品、單位、倉庫、儲位、入出庫、即時調撥及庫存流水。需要以可稽核的方式處理盤點差異、既有庫存建帳及錯誤過帳更正。

## 決策（供產品確認）

- 盤點以倉庫為界，在建立時記錄該倉庫庫存版本及正庫存快照；不鎖住現場作業。任何後續庫存異動都使整張盤點無效，避免把不同時間點的庫存混算。
- 盤點差異以獨立 adjustment 單據與正負流水記錄；數量為非負整數，零數量有效。
- Opening 每個租戶／商品／倉庫／儲位至多一筆，只能在該位置完全沒有庫存流水時建立。
- 沖銷建立連結原單的新過帳單據，保留原始流水，不修改或刪除歷史。支援整筆沖銷且同來源至多一次。
- 過帳及沖銷只允許 Owner。沖銷必須附原因；任何步驟造成負庫存時整個交易回滾。
- 盤點草稿／過帳、期初唯一性、沖銷唯一性、文件及流水一致性均由 PostgreSQL 約束或 trigger 加強，避免只依賴 UI。

## 後果與待確認

實作採粗粒度倉庫版本，因此同倉任一異動會讓盤點重開；好處是避免競態，代價是盤點作業可能重來。使用者尚未確認是否需要盲盤、盤點凍結／截點、差異審批、多次覆盤、部分沖銷、成本／會計影響或期初匯入。PR 合併前須審查以上假設。
