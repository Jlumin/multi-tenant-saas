# ADR 0005：WMS 主檔與整數包裝換算

日期：2026-10-26。WMS-001 / #13。依已確認需求先提供一般商品／零件、整數單位、可能拆零、多倉與儲位主檔；庫存交易屬後續工作。

## 決定

- 每個 SKU 有不可變的基本單位與專屬 `BASE` 單位紀錄（比例 1）。額外包裝單位以正整數 `factor` 換算成基本單位；換算由 server 計算，暫供試算，不建立庫存或異動。
- 包裝代碼、換算比例與版本不可更新或刪除。若包裝內容改變，停用舊單位，新增不同代碼；既有比例仍可稽核。
- 每個租戶可有多個倉庫，代碼在租戶內唯一。每倉建立不可停用的 `UNASSIGNED`／未分配儲位，後續可新增實體位置；儲位代碼在倉庫內唯一。
- 所有四種主檔都有租戶範圍與 version。建立及更新只允許 Owner；Member 可查詢及試算。兩種角色皆不能直接刪除紀錄，改用停用保留歷史。
- 使用 WMS 自己的 `wms_*` 表與 service；資料庫使用複合外鍵、唯一索引、CHECK 與保護 trigger 維護結構不變條件。租戶會員授權仍由 tenancy 公開契約決定。

## 安全及資料限制

API 從驗證 session 及有效 membership 決定租戶與角色，不使用 body 中的 tenant ID 作為授權依據。子資源列表、讀取及更新以租戶與父資源共同篩選；未知或外租戶的父資源回 404。寫入以租戶列鎖、角色重查、版本比對及 metadata audit 放在同一交易。

數量、比例為正整數；每單次數量上限 2,147,483,647，比例上限 1,000,000，換算後同樣不得超過數量上限。溢位拒絕，不四捨五入。此上限是本主檔／試算 API 的實作選擇，不應視為已核定未來帳本容量。

資料庫預設列保護由 trigger 與 CHECK 約束；具資料庫擁有者權限的人仍能更改結構或停用 trigger，所以不宣稱抵抗 DBA。營運資料庫角色分權與正式留存／封存政策待後續設計。

## 不在本決策內

不建立庫存餘額、庫存流水、入出庫、盤點、調撥、負庫存規則或正式過帳；不預填真實 SKU、地點與包裝比例；不決定批號、效期、序號或條碼。這些項目由後續 Issue 和已確認的商業規則定義。
