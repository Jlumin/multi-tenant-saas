# ADR 0006：WMS 庫存流水與入出庫過帳

日期：2026-10-27。WMS-002 / #15。業主確認：只有 Owner 可過帳、禁止負庫存；第一版先做一般入庫／出庫，期初庫存另開階段。

## 決定

- 庫存餘額由已過帳的 append-only 異動流水維護；禁止直接改餘額。交易將狀態、流水、餘額、冪等鍵與 metadata audit 一起提交或回滾。
- Member 與 Owner 可建立、編輯、查詢及取消草稿；Owner 才能過帳。API 每次重查有效 membership 與租戶狀態。
- 入庫使用正向基本單位數量；出庫使用負向異動。資料庫 trigger 維護整數餘額並拒絕負數或超出整數上限。多品項任一不足時整張回滾。
- 一張文件的明細保存建立時商品單位、包裝倍率與版本快照。過帳重新檢查主檔啟用狀態與倍率，舊單不因後續改名而換算。
- 租戶列鎖序列化寫入；過帳冪等鍵在租戶內唯一並綁定文件內容，同鍵同內容重播已完成結果，不同文件或內容衝突拒絕。
- 已過帳文件及流水不可更新或刪除。此階段沒有沖銷文件；錯誤更正流程由後續需求定義。

## 資料邊界與限制

`wms_documents`、`wms_document_lines`、`wms_stock_balances`、`wms_stock_movements` 與 `wms_posting_keys` 均由 WMS 擁有。複合租戶外鍵將文件、商品、倉庫、儲位、單位及流水鎖在同一租戶。記帳單位是商品基本單位整數；資料庫／JavaScript 上限為 2,147,483,647，溢位拒絕。

目前 API 提供基本餘額與異動列表，含租戶範圍、篩選及分頁；完整查詢介面、可視化、調撥、同倉移位、盤點調整、期初建帳、負向沖銷、批號／效期／序號、預留與訂單扣料不屬本 Issue。

不建立採購或銷售單，也不假設期初現場存量。若使用者需匯入既有數量，待後續期初建帳階段另定來源、數量核對、權限與稽核方式。

## 驗證

WMS-002 的隔離 PostgreSQL 測試涵蓋真實 session、Member/Owner 權限、兩租戶隔離、整張回滾、同鍵重播、併發出庫不可超賣、資料庫禁止改寫及 audit 失敗 rollback。逐項結果見 [WMS-002 驗證報告](../verification/WMS-002.md)。
