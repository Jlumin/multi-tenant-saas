# ADR 0007：WMS 即時調撥與同倉移位

- 狀態：Draft，供 WMS-004 / Issue #19 審查
- 日期：2026-10-27（Asia/Taipei）

## 背景

WMS-003 已提供 tenant-scoped 庫存餘額及不可變異動帳。下一步需要將未分配儲位庫存移入實體儲位，或將庫存移至另一倉。產品尚未決定是否需要在途簽收。

## 暫定決策

本 Issue 以同一 PostgreSQL 交易完成來源扣減與目的增加。兩個異動列共用同一張不可變調撥單與明細；同倉不同儲位是移位，跨倉是即時調撥。Member 可建草稿及查詢，只有 Owner 可過帳。來源數量不足或目的整數上限溢位時整張拒絕。此為先行實作以供審查的假設，尚非使用者已核定之商業政策。

## 資料完整性

- 單據保留來源倉，並以目的倉與每行目的儲位表達去向；來源／目的資料均使用 tenant-scoped 關聯。
- PostgreSQL movement trigger 僅接受與已過帳單據、明細、商品、方向、來源／目的位置及過帳操作者相符的異動。
- stock movements 以單據、明細、倉庫及儲位唯一，允許同一明細各有一筆來源與目的異動，但不允許重複插入同一側。
- 異動 trigger 在同交易更新餘額，並拒絕負庫存或整數溢位；tenant advisory lock 與 posting key 延續 WMS-002 防重送及併發保護。

## 不包含

在途庫存、部分收貨、差異處理、調撥取消、盤點、期初建帳及沖銷。若人工審查確認需要在途流程，應先重訂狀態與資料模型，不把此模式標示為完整在途管理。
